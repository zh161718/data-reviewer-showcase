# 数据复盘员 Agent 展示网站

一个用于展示「数据复盘员」Agent 的单页网站：每天 21:00 把飞书群里的成交截图，自动变成五段式复盘文档并投递回群。

## 怎么看

直接用浏览器打开 `index.html` 即可预览，无需安装任何软件。

## 页面包含什么

| 区块 | 说明 |
| --- | --- |
| Hero + 产品模拟窗 | 一次运行的核心数字与输出（示例数据，均为虚构） |
| 功能特性 | OCR 提取、逐笔核对、五段式模板、量化改进点、带价位策略、定时投递 |
| 模拟体验 | 点击步骤查看从收图到投递的完整流程（纯前端模拟） |
| 工作流程 | 收图 → 识别核对 → 生成复盘 → 投递反馈 |
| 复盘示例 | 五段式示例 / 量化改进点 / 带价位策略（演示数据均为虚构） |
| 核心规范 | Profile v1.2 的六条硬规则 |
| 能力边界 | 能独立完成 / 明确不做 / 需要人工介入 |
| 安全说明 | 纯静态、无真实数据、不接 API |
| 常见问题 | 触发方式、输出位置、数据安全等 |

## 怎么改内容

所有内容都在 `index.html` 一个文件里。用任意文本编辑器（记事本、VS Code 等）打开，搜索关键词定位：

| 想改的内容 | 在文件里搜索 |
| --- | --- |
| 顶部主标题 / 副标题 | `把每天的成交截图` |
| Hero 示例数字 | `数据复盘-2026-08-17` |
| 功能特性卡片 | `截图 OCR 提取` |
| 模拟体验各步骤 | `收到 5 张成交截图` |
| 复盘示例 | `数据复盘 · 2026-08-17（示例）` |
| 核心规范 | `它被要求严格遵守这些规则` |
| 能力边界 | `能做 · 不能做 · 需要人` |
| 常见问题 | `需要开发或写代码吗` |

页面里的交易数字（笔数、金额、价差、价位）都是演示用示例数据，公开展示前请保持为虚构样例。

## 怎么上线

这是一个纯静态网站（一个 HTML 文件），可部署到任何静态托管平台：

- ChatGPT Sites（在生成它的对话里直接说"发布"，权限选 Anyone on the internet）
- GitHub Pages / Gitee Pages
- Vercel / Netlify
- 公司内部服务器或对象存储（OSS / COS）
